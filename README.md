## 官方法律資料匯入

`judicial_open_data.py` 使用司法院資料開放平臺目錄 API，預設盤點裁判書、大法官解釋、憲法法庭判決與實體裁定的資源清單，不下載檔案：

```bash
python judicial_open_data.py --show-resources
```

先下載少量資源確認磁碟空間與格式：

```bash
python judicial_open_data.py --download-limit 5
```

納入法務部全國法規資料庫的繁體中文法規快照：

```bash
python judicial_open_data.py --include-laws --download-limit 2
```

下載上限計算的是「資源檔案數」，不是裁判篇數。檔案會放在 `raw_exams/judicial_open_data/`，資源目錄、下載狀態和 SHA-256 會記錄在 SQLite manifest，重跑時會跳過已完成的檔案。這個工具保存官方原始檔，尚未解壓、解析或依民法、刑法、行政法等領域分類；使用 `--download-limit -1` 會下載所有列出的資源，請先確認磁碟容量。

`harvest_training_data.py` 和 `mass_harvest.py` 是以少量程式內範例產生合成訓練資料的舊工具，不是官方判決爬蟲；不要把它們輸出的 AI 合成內容當成真實判決或標準答案。學者見解全文有第三方著作權，不會在未確認授權前批次蒐集；後續可先納入合法公開的書目、引用與開放授權全文。

資料來源：

- [司法院資料開放平臺開發指引](https://opendata.judicial.gov.tw/DevelopmentGuide)
- [司法院資料開放宣告](https://opendata.judicial.gov.tw/LicenseTerms)
- [法務部全國法規資料庫 OpenAPI](https://law.moj.gov.tw/api/swagger)
